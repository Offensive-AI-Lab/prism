# Data card

The training records are hosted at
[Offensive-AI-Lab/prism-training-dataset](https://huggingface.co/datasets/Offensive-AI-Lab/prism-training-dataset).
The dataset is private pending redistribution review.
`scripts/download_dataset.py` fetches and verifies the pinned files;
`scripts/check_dataset.py` checks their records, counts, and split membership.

## Training records

| field | contents |
|---|---|
| `id` | stable record identifier |
| `source_dataset` | source key from the table below |
| `prompt` | instruction-rich user prompt, drawn from the sources below |
| `response` | target model's answer to `prompt` (sampled) |
| `instruction_set` | generated instruction labels: a bullet list stored as text, generated from `prompt` alone at temperature 0.3 |
| `metadata` | source, paraphrase group id, generation parameters |

The fixed request used for instruction-set generation lives in code. It is not
stored in each released record.

### Sources pulled at generation time

| source key | upstream | license notes |
|---|---|---|
| `if_eval` | google/IFEval (HF) | Apache-2.0 |
| `if_multi_constraints` | allenai/IF_multi_constraints_upto5 (HF) | ODC-By, as recorded in the source inventory |
| `ultrachat` | HuggingFaceH4/ultrachat_200k (HF) | MIT per its HF dataset card (a filtered derivative of the UltraChat corpus) — verify the card before redistributing derived data |

`response` and `instruction_set` were generated by Qwen3.5-9B. The source
licenses and generated fields are part of the pending redistribution review.

### Labels

`instruction_set` is generated from the prompt alone: the target model is shown
`prompt` alone and asked to list the instructions it contains (temperature
0.3). The generated records are then cleaned — rules + LLM-judge filter, a
≤6-bullet cap, template-leak and word-fragmentation gates — producing a
`valid_record_ids.json` mask that every training loader applies. Activations
are extracted per target model; the records are shared across target models.

Qwen3.5-9B generates both responses and labels, and the judge-filter mask
applies to training and evaluation splits. IFEval contributes training prompts,
so evaluation on IFEval or overlapping derivatives is not an independent
held-out evaluation.
